Executive Summary

Headline Visual polish high. Editorial heading recipe disciplined. Brand identity coherent. But product as usable artifact leaks across navigation, accessibility, mobile, and motion control. Deck looks like premium agency, behaves like demo reel.

Biggest red flags
  1. Nav labels stale — say "WHY US / ABOUT" while slides are "Who We Are / Our Team". Buyer sees broken promise.
  2. Auto-advance lock — roster (5s) + CardSwap (3s) rotate without user pause control. WCAG SC 2.2.2 fail.
  3. Mobile WebGL un-gated — Hyperspeed, LightRays, PrismaticBurst mount on phone. Self-violates prod.md line 22.
  4. Empty-canvas flash — SLIDE_MOUNT_RADIUS = 0 + lazy chunk = black screen between slides.

5. Three Redesign Proposals

Proposal A — Nav Truth Pass

Words + Findable fix

Now:

Intro · Why Us · About · Services · Clients · Case Study · Contact

Fix to:

Cover · Who We Are · Team · Services · Clients · Case Studies (7) · Contact

Plus:

  • Slide counter 03 / 13 left-anchored, always visible (don't hide with nav)
  • Tiny vertical dot column right edge, current slide teal, click to jump
  • Replace role="menubar" / role="menuitem" with plain <nav aria-label="Deck"><ul><li><a>

Expected impact: Findable 2→4, Words 2→4, Accessible 1→2. Effort: 4 hr.

Proposal B — Motion Control + Reduced-Motion Pass

Single hook useDeckMotion() returns { reduceMotion, paused, togglePause }:

// All auto-advancers consume it
const { paused, reduceMotion } = useDeckMotion();
useEffect(() => {
  if (paused || reduceMotion) return;
  const t = setTimeout(advance, 5000);
  return () => clearTimeout(t);
}, [paused, reduceMotion, activeIndex]);

Add single floating button bottom-right:

[ ⏸ Auto-play ]   →   [ ▶ Auto-play ]

Gate inside WebGL components:

const isMobile = useIsMobile();
if (isMobile) return null;  // or low-fi static gradient fallback

For scrollTo:

const reduceMotion = window.matchMedia('(prefers-reduced-motion: reduce)').matches;
container.scrollTo({ top, behavior: reduceMotion ? 'auto' : 'smooth' });

Expected impact: Accessible 1→3, Time 2→4, Error Tolerance 2→3. Effort: 1 day.

Proposal C — Slide Mount Resilience

Now: SLIDE_MOUNT_RADIUS = 0 + <SlideFallback> empty + lazy import = black flash between slides.

Fix three-part:

1. Bump radius to 1 when on desktop:

const SLIDE_MOUNT_RADIUS = useIsMobile() ? 0 : 1;

2. Skeleton placeholder instead of empty:

const SlideFallback = ({ index }: { index: number }) => (
  <section className="slide" aria-busy="true">
    <div className="opacity-30 text-xs tracking-[0.3em] text-primary">
      {String(index + 1).padStart(2, '0')} / {slides.length}
    </div>
  </section>
);

3. Modulepreload hint for next chunk on mount:

useEffect(() => {
  const nextIdx = currentSlide + 1;
  if (nextIdx < slides.length) {
    slides[nextIdx]?.preload?.();
  }
}, [currentSlide]);

Expected impact: Effectiveness 3→4, Time 2→3. Effort: 4 hr.
