# Typography

## Type Scales
Hand-pick font sizes rather than using mathematical ratios.
- *Example Scale*: 12, 14, 16, 18, 20, 24, 30, 36, 48, 60, 72.
- Use `px` or `rem` (not `em`) for font-size to guarantee you stay on the system.

## Font Selection
- Prioritize neutral sans-serifs for UI.
- Choose typefaces with at least 5 weights.
- Trust popular fonts (Google Fonts sort by popularity) as an indicator of quality.

## Line Height
Line-height is inversely related to font size and line length.
- **Body text**: 1.5–1.7 line-height.
- **Headings**: 1.0–1.2 line-height.
- **Optimal line length**: 45–75 characters per line.

## Alignment
- Left alignment is standard for readability.
- Avoid justified text on the web without hyphenation — it creates ugly "rivers" of white space.
- Center alignment suits only short headline text.

## Letter Spacing
- **Display/large text**: Tighten letter-spacing slightly.
- **All-caps text**: Increase letter-spacing to improve readability.
